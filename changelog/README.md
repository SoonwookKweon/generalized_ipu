# 변경 이력 관리 규약

이 폴더는 `generalized-ipu`의 모든 변경 기록을 보관한다. 변경 이력은 이 폴더에서만 관리하며, 소스 코드의 docstring이나 `docs/` 아래의 문서에는 기입하지 않는다.

## 역할 분담

| 위치 | 서술 대상 | 시제 |
| --- | --- | --- |
| `changelog/` | 무엇이 언제 어떻게 바뀌었는가 | 과거 |
| `docs/` | 현재 라이브러리가 무엇인가 | 현재 |
| docstring | 해당 모듈이 지금 무엇을 하는가 | 현재 |

따라서 `docs/`와 docstring에는 "기존에는 ~였다", "~로 변경하였다", "이전 판에서는" 같은 서술을 두지 않는다. 문서를 읽는 사람이 과거를 알 필요 없이 현재 상태만으로 이해할 수 있어야 한다.

## 파일 명명

`YYYY-MM-DD_주제.md` 형식을 사용한다. 하루에 여러 건을 기록할 경우 주제를 달리하여 파일을 나눈다.

## 항목 구성

각 항목은 다음 네 요소를 갖춘다.

1. **대상:** 변경된 파일 또는 모듈
2. **내용:** 무엇을 어떻게 바꾸었는가
3. **사유:** 왜 바꾸었는가
4. **영향:** 사용자가 인지해야 할 동작 변화. 없으면 "없음"으로 명기한다
