# 2026-09-06 구조 정정과 결함 해결

`docs/03_명세_대비_구현_현황.md`에서 식별한 결함을 처리한 기록이다. 시험 46건을 신규 작성하여 전부 통과함을 확인하였다.

---

## 1. 패키지 구조 정상화

| 대상 | 내용 |
| --- | --- |
| `src/generalized_ipu/__init__,py` | `__init__.py`로 개명하고 공개 API를 재수출하도록 작성 |
| `src/generalized_ipu/engine.py/` | `engine/`으로 개명 |
| 여섯 개 하위 패키지 | `__init__.py`를 추가하고 공개 API를 재수출 |
| 저장소 최상위 | `pyproject.toml` 신규 작성 (setuptools, src 배치, 의존성 numpy·pandas·scipy) |

- **사유:** 확장자 구분자가 쉼표인 파일과 `.py`로 끝나는 디렉터리 때문에 패키지를 임포트할 수 없었다.
- **영향:** `pip install -e .` 후 `import generalized_ipu`가 성립한다.

## 2. 목표 구간 일원화

| 대상 | 내용 |
| --- | --- |
| `constraints/interval.py` | `IntervalTarget`을 동결 데이터 클래스로 재작성하고 `normalize_targets`, `compute_update_ratios`, `bound_violations`를 벡터 연산 함수로 분리 |
| `constraints/base.py` | 모든 제약이 `(column_names, lower, upper)`를 보유하도록 기반 클래스를 재정의하고, 구간별 비율 산출의 기정 구현을 제공 |
| `engine/core.py` | 목표를 `lower`와 `upper`로 받고, 비율 산출을 `constraints`에 위임 |

- **사유:** 반복 루프가 목표를 스칼라로 가정하여 구간 제약이 적용되지 않았고, 비율 산출 논리가 두 곳에 중복되어 있었다.
- **영향:** 생성자 서명이 `GeneralizedIPUEngine(matrix, targets, ...)`에서 `GeneralizedIPUEngine(matrix, lower, upper=None, ...)`으로 바뀌었다. `BoundChecker`가 사전 대신 배열 기반으로 동작한다.

## 3. 영 셀 처리의 축과 극성 정정

| 대상 | 내용 |
| --- | --- |
| `constraints/rules.py` | 규칙 평가의 대상을 표본 자료의 행에서 제약 열의 범주 조합 표로 변경하고, 유효한 쪽이 참인 `build_validity_mask`를 표준 반환값으로 지정 |
| `constraints/zeros.py` | `StructuralZeroMask`를 제약 열 축의 열 선택 연산으로 재작성하고, 마스크 길이가 기본 단위 수와 같으면 예외를 발생시키는 축 검사를 추가. 구조적 영에 양수 목표가 들어온 경우의 처리(`enforce_zero_targets`)를 신설 |
| `constraints/zeros.py` | `ZeroCellResolver`가 표본 영 열을 먼저 탐지한 뒤 해당 열에만 좌표 형식으로 $\varepsilon$를 주입하도록 변경. 조밀 변환을 제거 |
| `matrix/builder.py` | 유효 마스크를 블록별로 받아 결합 이전에 해당 열을 제외하는 색인 원천 제외를 구현 |

- **사유:** 두 유형의 영은 제약 열의 성질인데 구현은 기본 단위 축에 마스크를 적용하였고, `toarray()` 호출로 희소 표현의 이점이 사라졌다.
- **영향:** `LogicalRuleParser.parse_and_apply`가 `build_validity_mask`로 대체되었고 반환값의 극성이 반대가 되었다. `StructuralZeroMask.apply_mask`가 `select_valid_columns`로 대체되었다.

## 4. 속성 행렬 구축의 완성

| 대상 | 내용 |
| --- | --- |
| `matrix/builder.py` | 블록 명세(`ColumnBlock`, `CrossTabBlock`, `CoarseBlock`)를 도입하고, 행렬과 열 이름, 블록 구간, 기본 단위 주키를 함께 담는 `AttributeMatrix`를 반환하도록 변경 |
| `hierarchy/mapper.py` | N차원 결합 분포를 기본 단위별 셀 수량으로 집계하는 `crosstab_to_base`를 신설. 조밀 중간 산출물 없이 좌표 형식으로 직접 구축 |
| `constraints/tensor.py` | `TensorTarget`이 차원 이름과 범주 목록을 보관하고 셀 이름과 다중 색인을 산출하도록 재작성. 논리 규칙 평가용 `category_frame`을 신설 |
| `hierarchy/category.py` | 매핑 행렬 구축을 사전 조회 기반으로 바꾸어 복잡도를 낮추고, 열 합이 1인지 검사하는 정합성 검증을 추가 |

- **사유:** N차원 텐서와 범주 위계가 속성 행렬에 결합되지 않았고, 제약 열 이름의 출처가 없어 진단 보고서를 생성할 수 없었다.
- **영향:** `UnifiedSparseMatrixBuilder.build_matrix(configs)`가 `build(blocks, validity_masks=None)`으로 대체되었다.

## 5. 계층 검증과 집계 경로 보강

| 대상 | 내용 |
| --- | --- |
| `hierarchy/tree.py` | 주키 유일성과 부모키 참조 무결성 검사를 추가. `parent_level` 지정과 추론, 조상 경로 탐색, 기본 계층과의 관계 판정을 신설 |
| `hierarchy/mapper.py` | 기본 계층보다 상위 계층의 속성을 하위 기본 단위로 방송하는 경로와, 두 계층 이상 떨어진 하위 계층의 다단 누적 합산을 구현 |

- **사유:** 결측 부모키가 조용히 0으로 집계되고, 지역 단위 제약을 가구 기본 단위에 부여할 수 없었다.
- **영향:** `add_level`에 `parent_level` 인자가 추가되었다. 부모 계층 후보가 여럿이면 명시하지 않은 경우 예외가 발생한다.

## 6. 반복 엔진의 종료 보고와 이력 수집

| 대상 | 내용 |
| --- | --- |
| `engine/core.py` | 가중치, 수렴 여부, 종료 사유, 소요 회차, 최종 진단, 가중합, 이력을 담는 `IPUResult`를 반환하도록 변경. 완화 계수 `eta`를 생성자 인자로 승격. `ConvergenceTracker`를 회차마다 호출 |
| `engine/convergence.py` | 구간 위반량 기준으로 절대 격차, 상대 격차, 구간 위반율을 산출하는 `ConvergenceReport`를 반환하도록 재작성. 두 허용 한계 중 하나만 충족해도 만족으로 판정 |
| `engine/bounds.py` | 분모 보호 상수를 모듈 상수로 분리하고, 배율 절단과 하한 접촉 건수를 `BoundStatistics`로 기록 |
| `matrix/scaling.py` | 전치 행렬과 행 합을 재사용하는 인스턴스 형태를 추가. 정적 메서드는 유지 |

- **사유:** 수렴과 최대 반복 도달을 호출자가 구분할 수 없었고, 목표가 0인 제약 열이 판정에서 제외되어 구조적 영 처리 실패가 수렴으로 보고될 수 있었다.
- **영향:** `fit()`의 반환형이 `np.ndarray`에서 `IPUResult`로 바뀌었다. 최종 가중치는 `result.weights`로 접근한다.

## 7. 진단과 입출력 보강

| 대상 | 내용 |
| --- | --- |
| `diagnostics/distribution.py` | 신규 작성. 기술 통계, 변동 계수, 정규화 엔트로피, 상위 점유율, 유효 표본 수, 하한 접촉 수, 극단 배율을 산출하고 주의 항목을 열거 |
| `diagnostics/tracker.py` | 회차별 기록을 `IterationRecord`로 구조화하고 표 변환과 이력 형태 진단을 추가 |
| `diagnostics/reporter.py` | 구간 위반량 기준의 보고서로 재작성하고 제약별 요약 집계를 추가 |
| `io/loaders.py` | 키 열 자료형 통일과 속성 열 결측 처리를 신설. Parquet 적재와 계층 트리 일괄 구성을 추가 |
| `io/exporter.py` | 주키 결합 방식의 가중치 부착, 하위 계층 전파, Parquet 저장, 확률적 반올림 정수화를 추가 |

- **사유:** 명세가 규정한 `WeightDistributionAnalyzer`가 없었고, 적합도만으로는 소수 개체의 가중치 과점을 탐지할 수 없었다.
- **영향:** `FitReportGenerator.generate_report`의 서명이 `(weighted_sums, lower, upper=None, column_names=None, column_owners=None)`으로 바뀌었다. `DatasetExporter.export_with_weights`에 주키 결합 인자가 추가되었다.
