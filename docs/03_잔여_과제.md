# 잔여 과제 (Open Items)

설계 명세(`design/00_초기구상.md`)와 용어 정의(`docs/01_용어와_정의.md`)가 규정하였으나 아직 구현되지 않은 항목이다. 항목별 처리 기록은 `changelog/`에서 관리한다.

---

## 1. 연산 가속

| 항목 | 내용 | 판단 |
| --- | --- | --- |
| Numba 또는 Cython 커널 | 명세는 `SparseScalingKernel`을 컴파일된 커널로 규정한다. 현재는 SciPy의 희소 연산을 사용한다. | 두 연산 모두 SciPy 내부의 컴파일된 커널을 호출하므로, 실측 없이 별도 가속 계층을 도입할 근거가 없다. 대규모 자료에서 반복 1회 소요 시간을 측정한 뒤 판단한다. |
| 전치 행렬 재사용 | `SparseScalingKernel`의 인스턴스 형태가 전치 행렬과 행 합을 보관한다. 정적 메서드는 회차마다 다시 계산한다. | 엔진은 인스턴스 형태를 사용한다. 정적 메서드는 단발 계산용으로 유지한다. |

## 2. 입출력

| 항목 | 내용 |
| --- | --- |
| Polars, PyArrow, SQLite 적재 | 명세가 규정한 형식 중 CSV와 Parquet만 지원한다. |
| 상위 진입점 | 자료 적재부터 결과 저장까지를 하나의 설정으로 실행하는 파이프라인 함수가 없다. 현재는 사용자가 여섯 단계를 직접 조립해야 한다. |
| 합성 자료 생성 | `DatasetExporter.integerize`는 확률적 반올림까지만 수행한다. 정수 가중치에 따라 기본 단위를 복제하여 개체 수준 합성 자료를 산출하는 절차가 없다. |

## 3. 제약과 계층

| 항목 | 내용 |
| --- | --- |
| 대범주 비율의 역전파 | 대범주 제약은 현재 별도의 제약 열로 취급하여 속성 행렬에 결합한다. 명세가 서술한 $M^{\top}$을 통한 소범주 차원 역전파는 구현하지 않았다. 두 방식의 수렴 특성 비교가 필요하다. |
| 다중 부모 계층 | 계층 트리는 단일 부모만 허용한다. 개체가 둘 이상의 상위 개체에 소속되는 구조는 지원하지 않는다. |
| 목표 정합성 사전 검사 | `MissingMarginEstimator`의 균형식이 등록된 제약표 사이의 모순은 반복 이전에 탐지한다. 균형식으로 명시되지 않은 제약표 사이의 총계 불일치는 여전히 탐지하지 않는다. 등록된 제약 전체를 훑어 균형식을 자동 유도하는 절차가 필요하다. |
| 분수 귀속의 가중치 동질성 | `ShareBlock`의 가중합이 상위 계층 개체 수와 일치하려면 한 상위 개체에 속한 기본 단위들의 가중치가 같아야 한다. 이 전제가 얼마나 깨졌는지 측정하거나 가중치를 상위 개체 안에서 묶는 기능이 없다. |
| 결측 구간의 확률적 해석 | 구간은 연역의 산물이며 그 안의 분포를 규정하지 않는다. 표본 오차로 인한 미공표에 신뢰구간을 부여하는 통계적 접근은 도입하지 않았다. |

## 4. 진단

| 항목 | 내용 |
| --- | --- |
| 수렴 궤적 시각화 | `ConvergenceTracker.to_frame`이 표를 반환할 뿐 도표를 생성하지 않는다. |
| 제약 간 상충 진단 | 미수렴 시 어느 제약 조합이 실현 불가능성을 유발하는지 지목하는 기능이 없다. 현재는 적합도 표의 상위 항목으로 사용자가 추정해야 한다. |

## 5. 성능 측정

대규모 자료에 대한 성능 기준선이 없다. 기본 단위 수, 제약 열 수, 비영 성분 수를 축으로 하는 측정 계획을 세우고, 장형 표 기반 구현과의 비교 근거를 확보해야 한다.
