# 용어와 정의 (Terminology and Definitions)

본 문서는 `generalized-ipu` 라이브러리의 설계, 구현, 문서 작성에 사용하는 모든 용어와 기호를 규정한다. 이후의 모든 코드, 주석, 문서, 커밋 메시지는 본 문서의 정의를 따른다. 정의가 서로 충돌할 경우 본 문서가 우선하며, 설계 명세(`design/00_초기구상.md`)는 본 문서에 종속된다.

- 문서 판번호: 1.0
- 적용 범위: `src/generalized_ipu/` 전체 및 `docs/` 전체

## 0. 표기 규약

| 대상 | 규약 | 예시 |
| --- | --- | --- |
| 집합 | 필기체 대문자 | $\mathcal{L}$, $\mathcal{F}$ |
| 행렬 | 정자 대문자 | $A$, $M$ |
| 벡터 | 굵은 소문자 | $\mathbf{w}$, $\mathbf{S}$ |
| 스칼라 성분 | 아래 첨자 소문자 | $w_i$, $a_{ik}$ |
| 반복 회차 | 위 첨자 괄호 | $\mathbf{w}^{(t)}$ |
| 행렬 전치 | 위 첨자 $\top$ | $A^{\top}$ |

벡터는 모두 열벡터로 취급한다. 색인 $i$는 항상 기본 단위를, 색인 $k$는 항상 제약 열을 가리키며 다른 의미로 재사용하지 않는다.

## 1. 자료 구조 계층의 용어

### 1.1 계층 (Level)

**정의.** 계층 $\ell$은 동일한 관측 단위를 가지는 하나의 표(table)이다. 라이브러리는 계층의 유한 집합 $\mathcal{L} = \{\ell_1, \dots, \ell_m\}$을 입력으로 받는다.

각 계층은 다음 세 요소로 식별된다.

- **계층명(level name):** 계층을 식별하는 문자열. 예를 들어 `"region"`, `"household"`, `"person"`이다.
- **주키(primary key):** 해당 계층의 행을 유일하게 식별하는 열이다.
- **부모키(parent key):** 해당 계층의 행이 소속되는 상위 계층 행의 주키를 담은 열이다. 최상위 계층의 부모키는 정의되지 않는다.

본 라이브러리에서 "상위 계층"은 포섭하는 쪽을, "하위 계층"은 포섭되는 쪽을 뜻한다. 즉 가구는 개인보다 상위 계층이다.

### 1.2 계층 트리 (Hierarchy Tree)

**정의.** 계층 트리는 정점 집합이 $\mathcal{L}$이고, 계층 $\ell$의 부모키가 계층 $\ell'$의 주키를 참조할 때 간선 $\ell' \rightarrow \ell$을 가지는 유향 비순환 그래프이다. 구현은 단일 근(root)을 가지는 트리를 전제하며, 순환이나 다중 부모를 허용하지 않는다.

**무결성 조건.** 계층 트리는 다음 네 조건을 모두 만족해야 한다.

1. 기본 계층이 정점 집합에 존재한다.
2. 모든 계층의 부모키가 자기 자신의 자료 표에 열로 존재한다.
3. 모든 부모키 값이 상위 계층 주키 값의 부분집합이다(참조 무결성).
4. 모든 계층의 주키에 중복 값이 없다.

`HierarchyTree.validate_integrity`가 네 조건을 모두 검사한다.

### 1.3 기본 가중치 부여 단위 (Base Weighting Unit)

**정의.** 기본 가중치 부여 단위, 줄여서 **기본 단위**는 가중치가 직접 부여되는 관측 단위이다. 기본 단위가 속한 계층을 **기본 계층(base level)**이라 하고 $\ell_{base}$로 표기한다. 기본 계층의 행 수를 $n$이라 하고, 각 행을 $i \in \{1, \dots, n\}$으로 색인한다.

기본 계층은 사용자가 명시적으로 지정하며 라이브러리가 추론하지 않는다. 기본 계층이 아닌 모든 계층의 속성은 집계 사상을 거쳐 기본 계층의 좌표계로 옮겨진다.

### 1.4 집계 사상 (Aggregation Mapping)

**정의.** 계층 $\ell$의 속성 열 집합 $C_\ell$에 대한 집계 사상 $\Phi_\ell$은 계층 $\ell$의 자료를 기본 계층의 행 좌표계 위에 놓인 $n \times |C_\ell|$ 실수 행렬로 옮기는 사상이다. 세 경우로 나뉜다.

- 계층 $\ell$이 기본 계층의 **하위** 계층이면 부모키를 기준으로 속성 값을 합산한다. 기본 단위 $i$의 값은 $i$에 소속된 하위 계층 행들의 속성 값 합계이며, 소속된 행이 없으면 0이다.
- 계층 $\ell$이 기본 계층의 **상위** 계층이면 상위 계층 행의 속성 값을 그에 속한 모든 기본 단위에 그대로 방송(broadcast)한다.
- 계층 $\ell$이 기본 계층 자신이면 항등 사상이다.

## 2. 제약 조건 계층의 용어

### 2.1 제약 열 (Constraint Column)

**정의.** 제약 열 $k$는 목표값 하나가 대응되는 최소 제약 단위이다. 전체 제약 열의 수를 $K$라 하고 $k \in \{1, \dots, K\}$로 색인한다.

1차원 주변표의 범주 하나, $N$차원 교차표의 셀 하나, 대범주 하나가 각각 하나의 제약 열이 된다. 다시 말해 제약표는 제약 열의 묶음이며, 연산의 단위는 언제나 개별 제약 열이다.

### 2.2 속성 행렬 (Attribute Matrix)

**정의.** 속성 행렬 $A \in \mathbb{R}_{\ge 0}^{n \times K}$의 성분 $a_{ik}$는 기본 단위 $i$가 가중치 1을 가질 때 제약 열 $k$의 가중합에 기여하는 수량이다.

$a_{ik}$는 이진 지표에 한정되지 않는다. 기본 단위가 가구이고 제약 열이 "20대 남성 수"인 경우 $a_{ik}$는 해당 가구에 속한 20대 남성의 인원수가 된다. 이 점에서 속성 행렬은 설계 명세가 사용한 "지표 행렬(indicator matrix)"보다 넓은 개념이므로, 본 문서는 **속성 행렬**을 정식 용어로 채택한다.

속성 행렬은 `scipy.sparse.csr_matrix`로 표현한다. **비영 성분 수(number of nonzeros)**를 $\mathrm{nnz}(A)$로 표기하며, 반복 1회의 연산 복잡도는 $O(\mathrm{nnz}(A))$이다.

### 2.3 가중치 벡터와 가중합

**정의.** 가중치 벡터 $\mathbf{w} \in \mathbb{R}_{>0}^{n}$는 각 기본 단위의 복제 계수이다. 반복 $t$ 시점의 가중치를 $\mathbf{w}^{(t)}$로 표기한다.

**정의.** 가중합(weighted sum) 벡터는 다음과 같다.

$$\mathbf{S}^{(t)} = A^{\top}\mathbf{w}^{(t)}, \qquad S_k^{(t)} = \sum_{i=1}^{n} w_i^{(t)}\, a_{ik}$$

가중합은 현재 가중치가 재현하는 제약 열별 추정 총량이며, 목표값과 비교되는 유일한 대상이다.

### 2.4 목표 구간 (Target Interval)

**정의.** 제약 열 $k$의 목표는 하한 $L_k$와 상한 $U_k$의 쌍 $[L_k, U_k]$이며, $0 \le L_k \le U_k \le \infty$를 만족한다.

고정 스칼라 목표 $T_k$는 $L_k = U_k = T_k$인 **퇴화 구간(degenerate interval)**으로 취급한다. 따라서 라이브러리 내부에는 스칼라 목표라는 별도의 자료형이 존재하지 않으며, 모든 목표는 구간으로 정규화된 뒤 연산에 투입된다.

### 2.5 갱신 비율 (Update Ratio)

**정의.** 제약 열 $k$의 갱신 비율은 다음 구간별 정의 함수이다.

$$r_k^{(t)} = \begin{cases}
L_k / S_k^{(t)} & (S_k^{(t)} < L_k) \\
U_k / S_k^{(t)} & (S_k^{(t)} > U_k) \\
1 & (L_k \le S_k^{(t)} \le U_k)
\end{cases}$$

$S_k^{(t)} = 0$인 경우 비율이 정의되지 않으므로 $r_k^{(t)} = 1$로 두고, 해당 제약 열을 표본 영으로 분류하여 별도로 처리한다.

가중합이 목표 구간 안에 있으면 비율이 1이 되어 가중치를 변경하지 않는다. 이는 과잉 제약 상황에서 양립 불가능한 제약들이 가중치를 번갈아 끌어당기며 발생시키는 진동을 억제하기 위한 설계이다.

### 2.6 범주 위계와 매핑 행렬

**정의.** 하나의 속성에 대해 가장 세분화된 범주 집합을 **원자 스키마(atomic schema)** $\mathcal{F} = \{f_1, \dots, f_{K_f}\}$라 하고, 그 원소를 **소범주(fine category)**라 한다. 소범주들을 배타적으로 묶은 상위 범주를 **대범주(coarse category)**라 하며, 그 집합을 $\mathcal{C} = \{c_1, \dots, c_{K_c}\}$로 표기한다.

**정의.** 매핑 행렬 $M \in \{0,1\}^{K_c \times K_f}$는 대범주 $c_j$가 소범주 $f_k$를 포섭하면 $M_{jk} = 1$, 그렇지 않으면 $M_{jk} = 0$인 이진 행렬이다. 대범주 단위의 가중합은 $\mathbf{S}_{coarse} = M\,\mathbf{S}_{fine}$으로 얻는다.

**정합성 조건.** 매핑 행렬의 각 열의 합은 1이어야 한다. 즉 모든 소범주는 정확히 하나의 대범주에 속한다. 열의 합이 0이면 어느 대범주에도 포섭되지 않은 소범주가 존재한다는 뜻이고, 2 이상이면 대범주끼리 겹친다는 뜻이므로 두 경우 모두 입력 오류로 처리한다.

### 2.7 유효 마스크 (Validity Mask)

**정의.** 유효 마스크 $\mathcal{M} \in \{0,1\}^{K}$는 제약 열 $k$가 현실에서 성립 가능한 조합이면 $\mathcal{M}_k = 1$, 논리적으로 불가능한 조합이면 $\mathcal{M}_k = 0$인 벡터이다.

**극성 규약.** 본 라이브러리의 마스크는 **유효한 쪽이 1**이다. 부정 형태가 필요하면 `invalid_mask = ~validity_mask`로 파생시키되, 변수명에 극성을 반드시 드러낸다. 또한 유효 마스크의 길이는 제약 열의 수 $K$이며 기본 단위의 수 $n$이 아니다. 길이가 $n$인 마스크를 넘기면 예외가 발생한다.

### 2.8 구조적 영 (Structural Zero)

**정의.** 구조적 영은 법률적, 생물학적, 논리적 이유로 모집단에 존재할 수 없는 범주 조합에 대응하는 제약 열이다. 5세 운전면허 소지자나 남성 임신부가 그 예이다.

구조적 영 제약 열은 $\mathcal{M}_k = 0$이며, 속성 행렬 구축 단계에서 해당 열의 색인을 아예 할당하지 않는다. 이 처리를 **색인 원천 제외(index dropping)**라 한다. 목표표에 구조적 영 위치의 값이 0보다 크게 입력된 경우는 자료 오기입으로 간주하여 0으로 강제하거나 유효 범주로 재배분한다.

### 2.9 표본 영 (Sampling Zero)

**정의.** 표본 영은 모집단에는 존재하지만 표본에 우연히 포착되지 않아 $S_k = 0$이면서 $L_k > 0$인 제약 열이다.

표본 영은 갱신 비율의 분모를 0으로 만들어 반복을 중단시킨다. 이를 회피하기 위해 유효 제약 열에 한하여 미세 의사 빈도 $\varepsilon$를 주입한다.

$$\tilde{a}_{ik} = a_{ik} + \varepsilon\,\mathcal{M}_k, \qquad \varepsilon = 10^{-5}\ \text{(기정값)}$$

구조적 영에는 $\mathcal{M}_k = 0$이 곱해지므로 $\varepsilon$가 주입되지 않는다. 이 연산을 행렬 전체에 적용하면 속성 행렬이 조밀(dense) 행렬로 바뀌어 희소 표현의 이점이 사라지므로, 표본 영으로 판정된 제약 열에만 국소적으로 적용한다.

### 2.10 구조적 영과 표본 영의 구별 기준

| 구분 | 판정 근거 | 모집단에서의 참값 | 처리 방식 |
| --- | --- | --- | --- |
| 구조적 영 | 도메인 규칙 | 0 | 색인 원천 제외, 목표값 0 강제 |
| 표본 영 | 표본 관측 결과 | 양수 | $\varepsilon$ 평활 후 정상 조정 |

두 유형을 혼동하면 두 방향의 오류가 발생한다. 구조적 영을 표본 영으로 오인하면 불가능한 개체에 가중치가 배분되고, 표본 영을 구조적 영으로 오인하면 실재하는 범주가 영구히 0으로 고정된다.

### 2.11 결측 셀 (Missing Cell)

**정의.** 결측 셀은 제약표에 대응하는 값이 공표되지 않은 제약 열이다. 비공개 처리, 반올림 공표, 미공표가 원인이며, 모집단에서의 참값은 알 수 없다.

결측 셀은 영 셀의 두 유형과 다음 점에서 구별된다. 구조적 영은 참값이 0임을 알고 있고, 표본 영은 참값이 양수임을 알고 있으나 표본에 잡히지 않았다. 결측 셀은 참값의 존재 여부가 아니라 **공표 여부**의 문제이며, 참값이 놓인 범위만을 다른 정보로부터 연역할 수 있다.

| 구분 | 판정 근거 | 모집단에서의 참값 | 처리 방식 |
| --- | --- | --- | --- |
| 구조적 영 | 도메인 규칙 | 0 | 색인 원천 제외 |
| 표본 영 | 표본 관측 결과 | 양수, 값 미상 | $\varepsilon$ 평활 |
| 결측 셀 | 제약표의 공표 상태 | 미상 | 목표 구간을 연역 |

### 2.12 균형식 (Linear Balance)

**정의.** 균형식은 제약 열의 값들이 만족해야 하는 선형 조건이다.

$$\sum_{k} c_k x_k \in [T_{lo}, T_{hi}], \qquad c_k > 0$$

계수 $c_k$를 모두 1로 두면 주변표의 총계 조건이 되고, 계수를 달리 두면 서로 다른 제약표 사이의 정합 조건이 된다. $n$인가구 수 $H_n$과 총 가구원 수 $P$ 사이의 $\sum_n n H_n = P$, 가구 수 계급별 거처 수 $D_m$과 총 가구 수 $H$ 사이의 $\sum_m m D_m = H$ 가 후자의 예이다.

균형식은 결측 셀의 목표 구간을 연역하는 근거이며, 동시에 서로 다른 제약표의 총계가 어긋나는지를 반복 이전에 판정하는 근거이기도 하다. 좁혀진 구간에서 $L_k > U_k$가 되면 주어진 제약표들이 서로 모순된다.

### 2.13 분수 귀속 (Fractional Attribution)

**정의.** 분수 귀속은 상위 계층 개체 하나에 소속된 기본 단위 $m$개에 각각 $1/m$을 부여하여, 그 상위 계층 개체가 가중합에서 한 번만 세어지도록 하는 속성 행렬 구성 방식이다.

상위 계층의 속성을 기본 단위로 옮기는 기정 경로는 방송(1.4)이다. 방송은 같은 값을 소속 기본 단위마다 복제하므로 수량 속성에는 적합하지만 **개체 수**에는 적합하지 않다. 값이 1인 열을 방송하면 그 열의 가중합은 상위 계층 개체 수가 아니라 기본 단위 수가 되기 때문이다.

거처 계층에 가구 계층이 매달린 다가구주택 구조가 대표적이다. 거처 1호에 가구 $m$개가 있을 때, "거처 수"를 제약하려면 각 가구에 $1/m$을 부여해야 한다.

**전제.** 한 상위 개체에 속한 기본 단위들의 가중치가 서로 같을 때 해당 열의 가중합이 상위 계층 개체 수와 정확히 일치한다. 가중치가 벌어지면 가중치의 평균으로 계상되므로, 상위 계층 제약은 이 전제 위에서 해석한다.

## 3. 연산 계층의 용어

### 3.1 반복 갱신 방식

고전적 IPU는 제약 열을 하나씩 순회하면서 갱신 결과를 즉시 다음 제약 열의 계산에 반영하는 **순차 갱신(Gauss–Seidel 방식)**을 사용한다. 본 라이브러리는 한 회차 안에서 모든 제약 열의 비율을 동일한 $\mathbf{w}^{(t)}$로 계산한 뒤 한 번에 반영하는 **동시 갱신(Jacobi 방식)**을 채택한다.

**정의.** 동시 갱신식은 다음과 같다.

$$w_i^{(t+1)} = w_i^{(t)}\left(1 + \eta \cdot \frac{\sum_{k} (r_k^{(t)} - 1)\,a_{ik}}{\sum_{k} a_{ik}}\right)$$

여기서 $\eta \in (0, 1]$은 **완화 계수(relaxation factor)**이다. 괄호 안 둘째 항은 기본 단위 $i$가 관여하는 제약 열들의 갱신 비율 편차를 속성 수량으로 가중 평균한 값이다. $\eta = 1$이고 모든 $r_k$가 동일한 값 $r$이면 이 식은 $w_i \leftarrow r\,w_i$가 되어 고전적 비례 조정과 일치한다.

동시 갱신은 제약 열의 순서에 결과가 의존하지 않고 한 회차를 희소 행렬-벡터 곱 두 번으로 마칠 수 있다는 장점을 가진다. 반면 순차 갱신보다 수렴 속도가 느리고 $\eta$가 클 때 진동할 수 있다. 성능과 수렴 특성을 논할 때는 이 성질을 항상 명시한다.

### 3.2 가중치 경계 제어

**정의.** 다음 세 매개변수로 가중치의 발산과 소멸을 억제한다.

| 용어 | 식별자 | 의미 | 기정값 |
| --- | --- | --- | --- |
| 가중치 하한 | `weight_floor` | 갱신 후 가중치의 절대 하한 | $10^{-5}$ |
| 최소 변화 배율 | `min_ratio` | 한 회차에서 허용하는 $w_i^{(t+1)}/w_i^{(t)}$의 하한 | 0.1 |
| 최대 변화 배율 | `max_ratio` | 한 회차에서 허용하는 $w_i^{(t+1)}/w_i^{(t)}$의 상한 | 10.0 |

경계 제어는 회차별 **변화 배율**을 자르는 장치이지 가중치 자체의 상한을 두는 장치가 아니다. 두 개념을 구분하기 위해 전자를 **배율 제한(ratio cap)**, 후자를 **수준 제한(level cap)**이라 부른다. 라이브러리는 배율 제한과 가중치 하한을 제공하며, 수준 제한은 두지 않는다.

### 3.3 수렴 지표

**정의.** 제약 열 $k$의 **구간 위반량(bound violation)**은 다음과 같다.

$$v_k^{(t)} = \max\left(L_k - S_k^{(t)},\; S_k^{(t)} - U_k,\; 0\right)$$

가중합이 목표 구간 안에 있으면 $v_k^{(t)} = 0$이다. 이로부터 세 가지 수렴 지표를 정의한다.

| 지표 | 정의 | 용도 |
| --- | --- | --- |
| 절대 격차 (absolute difference) | $v_k^{(t)}$ | 목표값이 작은 제약 열의 과대 평가 방지 |
| 상대 격차 (relative gap) | $v_k^{(t)} / \max(L_k,\,1)$ | 규모가 다른 제약 열 사이의 비교 |
| 구간 위반율 (bound violation rate) | $\lvert\{k : v_k^{(t)} > 0\}\rvert / K$ | 전체 제약 중 미충족 비율 |

**정의.** **수렴(convergence)**은 모든 제약 열의 상대 격차 최댓값이 허용 한계 이하가 된 상태이다. **최대 반복 도달(iteration limit reached)**은 수렴이 아니다. 두 종료 사유는 진단 보고서에서 반드시 구분하여 표기한다.

### 3.4 실현 가능성

**정의.** 제약 집합의 **실현 가능 집합(feasible set)**은 다음과 같다.

$$\mathcal{W} = \left\{\mathbf{w} \in \mathbb{R}_{>0}^{n} \;:\; L_k \le (A^{\top}\mathbf{w})_k \le U_k,\ \ \forall k \right\}$$

$\mathcal{W} = \varnothing$인 제약 집합을 **과잉 제약(over-constrained)**이라 한다. 과잉 제약 상황에서 알고리즘은 수렴하지 않으며, 구간 제약과 배율 제한은 진동의 진폭만 억제한다. 따라서 미수렴을 보고할 때는 알고리즘의 실패로 단정하지 않고, 주어진 제약이 실현 불가능할 가능성을 우선 진단 가설로 제시한다.

## 5. 금지 용어와 대체 용어

문서와 코드에서 다음 표현을 사용하지 않는다. 좌열은 의미가 중의적이거나 기존 문서에서 혼용되어 온 표현이다.

| 사용하지 않을 표현 | 대신 사용할 표현 | 사유 |
| --- | --- | --- |
| 샘플, 시드 | 표본, 표본 자료 | 표기 혼용 방지 |
| 마진, 마지널 | 주변표, 제약표 | 음차 표기 배제 |
| 셀 | 제약 열 또는 교차표 셀 | 두 대상을 구분 |
| 레벨 | 계층 | 계층 구조와 범주 세분화 수준의 혼동 방지 |
| 그래뉼래리티 | 범주 세분화 수준 | 음차 표기 배제 |
| 피처 | 속성 또는 제약 열 | 기계 학습 용어와 구분 |
| 웨이트 | 가중치 | 표기 혼용 방지 |
| 수렴 실패 | 미수렴, 최대 반복 도달 | 원인 귀속을 단정하지 않음 |

`IPU`, `CSR`, `nnz` 등 정착된 영문 약어는 그대로 사용하되, 각 문서에서 처음 등장할 때 한 번 풀어 쓴다.
