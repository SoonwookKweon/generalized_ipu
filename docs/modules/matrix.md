# `generalized_ipu.matrix` — 속성 행렬 구축과 희소 연산

계층별 자료와 제약 정의를 하나의 희소 속성 행렬로 결합하고, 반복 루프가 사용하는 두 가지 희소 연산을 제공하는 패키지이다. `hierarchy`에 의존한다.

**책임 범위**

- 계층, 다차원 교차표, 범주 위계를 결합한 속성 행렬 $A$를 생성한다.
- 가중합 $\mathbf{S} = A^{\top}\mathbf{w}$를 계산한다.
- 갱신 비율로부터 새 가중치를 산출한다.

**책임 밖**

- 수렴 판정과 반복 제어는 `engine`이 담당한다.
- 목표값의 해석은 `constraints`가 담당한다.

## `builder.py` — 통합 속성 행렬 구축

### 블록 명세

속성 행렬은 블록의 가로 결합으로 구성한다. 블록은 네 종류이며, 모두 `name`으로 식별한다.

| 명세 | 인자 | 생성되는 제약 열 |
| --- | --- | --- |
| `ColumnBlock` | `name`, `level`, `cols` | 계층의 속성 열 하나마다 한 열. 이름은 `계층.열` |
| `CrossTabBlock` | `name`, `level`, `dims`, `weight_col=None` | 결합 분포의 셀 하나마다 한 열. 이름은 `차원=범주\|차원=범주` |
| `ShareBlock` | `name`, `level`, `dims=None` | 상위 계층의 범주 조합마다 한 열. `dims`를 생략하면 `계층명.count` 한 열 |
| `CoarseBlock` | `name`, `source`, `hierarchy` | 대범주 하나마다 한 열. 이름은 대범주명 |

`ShareBlock`은 상위 계층 개체를 기본 단위 좌표계에서 한 번만 세는 분수 귀속을 사용한다. 상위 계층 개체 하나에 기본 단위 $m$개가 소속되면 각 기본 단위에 $1/m$을 부여하므로, 그 열의 가중합은 상위 계층 개체 수가 된다. 같은 목적으로 `ColumnBlock`을 쓰면 상위 계층의 값이 소속 기본 단위마다 복제되어 중복 계상된다. 거처 계층 위에서 "가구 수 계급별 거처 수"를 제약하는 경우가 이 블록의 전형적 용도이다.

`CoarseBlock`은 먼저 구축된 소범주 블록을 `source`로 참조하여 $A_{coarse} = A_{fine} M^{\top}$을 계산한다. 참조 대상이 아직 구축되지 않았으면 예외가 발생한다. 구조적 영으로 제외된 소범주는 위계에서 자동으로 걷어내므로, 제외된 열을 포함한 채로 위계를 정의해도 무방하다.

### `AttributeMatrix`

구축 결과이다. 행렬과 그 열의 의미를 함께 담는다.

| 속성 및 메서드 | 설명 |
| --- | --- |
| `matrix` | 속성 행렬 $A$ (`csr_matrix`, $n \times K$) |
| `column_names` | 제약 열 이름 목록. 길이는 $K$ |
| `block_slices` | 블록 이름에서 열 구간으로의 대응 |
| `base_keys` | 기본 단위의 주키. 행 순서와 일치한다 |
| `n_units`, `n_columns`, `nnz` | 기본 단위 수, 제약 열 수, 비영 성분 수 |
| `block(name)` | 해당 블록의 부분 행렬을 반환한다 |
| `column_frame()` | 열마다 소속 블록과 이름을 담은 표를 반환한다 |

생성 시점에 행렬의 열 수와 열 이름 수가 일치하는지 확인한다.

### `UnifiedSparseMatrixBuilder`

`build(blocks, validity_masks=None) -> AttributeMatrix`가 블록 명세를 선언 순서대로 구축하여 가로로 결합한다. 최종 열 순서는 블록의 선언 순서와 각 블록 내부의 열 순서를 이어 붙인 것과 같다.

`validity_masks`는 블록 이름에서 그 블록의 유효 마스크로의 대응이며, 유효한 쪽이 참이다. 구조적 영 제약 열은 결합 이전에 제외되므로 최종 행렬에 색인이 할당되지 않는다. 마스크의 길이가 그 블록의 제약 열 수와 다르면 예외가 발생한다.

생성자는 기본적으로 계층 트리의 무결성을 먼저 검증한다.

**불변식**

1. 반환 행렬의 행 수는 기본 계층의 행 수 $n$과 같으며, 행 순서는 기본 계층 자료의 행 순서와 같다.
2. 반환 행렬의 열 수는 `column_names`의 길이와 같다.
3. 모든 성분은 0 이상이다.

## `scaling.py` — 희소 연산 커널

### `SparseScalingKernel`

인스턴스 형태와 정적 메서드 형태를 함께 제공한다. 인스턴스는 전치 행렬과 행 합을 미리 계산하여 보관하므로, 회차 수가 많은 반복에서는 인스턴스 형태를 사용한다. 엔진은 인스턴스 형태를 사용한다.

| 요소 | 설명 |
| --- | --- |
| `__init__(matrix)` | 행렬을 CSR로 보관하고 전치 행렬과 행 합을 계산한다 |
| `row_sums` | 행 합 $\sum_k a_{ik}$. 0인 행은 1.0으로 대체하여 나눗셈을 보호한다 |
| `inactive_units` | 행 합이 0인 기본 단위의 색인. 어떤 제약에도 관여하지 않아 가중치가 갱신되지 않는다 |
| `weighted_sums(weights)` | $\mathbf{S} = A^{\top}\mathbf{w}$. 복잡도는 $O(\mathrm{nnz}(A))$ |
| `next_weights(weights, ratios, eta=1.0)` | 동시 갱신식을 적용한다 |
| `compute_weighted_sum(matrix, weights)` | 정적 형태의 가중합 |
| `update_weights(weights, matrix, ratios, eta=1.0)` | 정적 형태의 갱신 |

### 동시 갱신식

$$w_i^{(t+1)} = w_i^{(t)}\left(1 + \eta \cdot \frac{\sum_{k}(r_k - 1)\,a_{ik}}{\sum_{k} a_{ik}}\right)$$

괄호 안 둘째 항은 기본 단위 $i$가 관여하는 제약 열들의 갱신 비율 편차를 속성 수량으로 가중 평균한 값이다.

**완화 계수.** $\eta$는 갱신의 보폭을 조절한다. 값이 작을수록 진동이 줄고 수렴이 느려지므로, 과잉 제약이 의심되는 경우 $\eta$를 낮추는 것이 첫 번째 대응이다. 엔진 생성자의 `eta` 인자로 지정한다.

**양수성.** 조정량이 $-1/\eta$ 이하가 되면 가중치가 0 이하로 떨어진다. 커널 자체는 양수성을 보장하지 않으며, 이 책임은 `engine.WeightBoundController`의 배율 제한과 가중치 하한에 있다.
