# generalized-ipu

다계층, 구간 목표, 다차원 교차표, 범주 위계를 동시에 수용하는 범용 반복 비례 갱신(Iterative Proportional Updating, IPU) 라이브러리이다.

> **개발 상태:** 개발 판(0.1.0.dev0). 여섯 가지 확장 요건이 모두 동작하며, 시험 75건과 검증 33건을 담은 예제 노트북을 갖추었다. 공개 API는 아직 고정되지 않았다. 미구현 항목은 [잔여 과제](docs/03_잔여_과제.md)에 정리하였다.

---

## 무엇을 하는 라이브러리인가

표본 미시 자료의 각 개체에 가중치를 부여하여, 가중합이 외부에서 주어진 다수의 집계 통계를 동시에 재현하도록 조정한다. 인구 합성(population synthesis), 교통 수요 예측, 보건 정책 시뮬레이션에서 표본을 모집단 규모로 확장할 때 사용한다.

기존 `pyipu` 대비 확장된 지점은 다음 여섯 가지이다.

| 항목 | 기존 | 본 라이브러리 |
| --- | --- | --- |
| 계층 구조 | 가구와 개인의 2계층 고정 | 임의의 $N$계층 트리 |
| 목표값 | 고정 스칼라 | 구간 $[L_k, U_k]$ 수용 |
| 제약표 차원 | 1차원 또는 2차원 | $N$차원 교차표 |
| 범주 세분화 수준 | 단일 수준 전제 | 소범주와 대범주의 혼재 수용 |
| 주변표의 결측 | 처리 없음 | 결측 셀의 목표 구간을 균형식으로부터 연역 |
| 상위 계층 개체 수 | 처리 없음 | 분수 귀속으로 다가구주택 구조를 제약에 반영 |

## 핵심 개념 요약

용어의 엄밀한 정의는 [용어와 정의](docs/01_용어와_정의.md)를 따른다. 아래는 개요이다.

- **기본 단위(base unit):** 가중치가 직접 부여되는 관측 단위이다. 사용자가 기본 계층을 지정하면, 다른 계층의 속성은 모두 기본 단위의 좌표계로 집계된다.
- **속성 행렬(attribute matrix) $A$:** $n \times K$ 희소 행렬이다. $a_{ik}$는 기본 단위 $i$가 가중치 1일 때 제약 열 $k$에 기여하는 수량이다.
- **가중합(weighted sum):** $\mathbf{S} = A^{\top}\mathbf{w}$. 목표와 비교되는 유일한 대상이다.
- **목표 구간(target interval):** 모든 목표는 $[L_k, U_k]$로 표현하며, 스칼라 목표는 $L_k = U_k$인 퇴화 구간으로 취급한다.
- **구조적 영과 표본 영:** 전자는 현실에 존재할 수 없는 조합이므로 색인 자체에서 제외하고, 후자는 표본에만 없는 조합이므로 미세 의사 빈도를 주입하여 나눗셈 오류를 피한다.
- **결측 셀과 균형식:** 값이 공표되지 않은 제약 열에는 목표 구간을 연역하여 부여한다. 근거는 셀 값들이 만족해야 하는 선형 균형식 $\sum_k c_k x_k \in [T_{lo}, T_{hi}]$ 이며, 계수를 달리 두면 서로 다른 제약표 사이의 정합 조건도 같은 틀로 표현된다.
- **분수 귀속(fractional attribution):** 상위 계층 개체 하나에 기본 단위 $m$개가 소속되면 각 기본 단위에 $1/m$을 부여하여, 그 개체가 가중합에서 한 번만 세어지게 한다. 거처 1호에 여러 가구가 사는 다가구주택 구조를 제약에 반영하는 방식이다.

반복 갱신은 한 회차 안에서 모든 제약 열의 비율을 동시에 계산하여 한 번에 반영하는 동시 갱신(Jacobi 방식)을 사용한다.

$$w_i^{(t+1)} = w_i^{(t)}\left(1 + \eta \cdot \frac{\sum_{k}(r_k^{(t)} - 1)\,a_{ik}}{\sum_{k} a_{ik}}\right)$$

## 문서 작성 규약

- 모든 용어는 [용어와 정의](docs/01_용어와_정의.md)의 정의와 대응표를 따른다. 같은 대상을 두 이름으로 부르지 않는다.
- 5절의 금지 용어 목록에 있는 표현을 사용하지 않는다.
- 새 개념을 도입할 때는 용어 문서에 정의를 먼저 추가한 뒤 코드와 문서에 사용한다.
- 변경 이력은 `changelog/`에서만 관리한다. `docs/`와 docstring은 현재 상태만 서술하며, 과거와의 대비나 변경 사실을 기입하지 않는다.

### docstring 규약

| 대상 | 내용 |
| --- | --- |
| 모듈 | 첫 줄에 한 문장 요약. 그 모듈이 존재하는 이유나 다른 선택지를 배제한 근거가 있으면 본문에 서술한다 |
| 클래스 | 한 줄 요약. 생성자 인자의 의미가 자명하지 않으면 이어서 서술한다 |
| 공개 메서드 | 한 줄 요약. 반환값의 순서, 예외 조건, 계약이 있으면 본문에 명시한다 |
| 비공개 메서드 | 한 줄 요약만 둔다 |

- 종결형은 평서형 현재 시제(`~한다`)로 통일한다.
- 코드를 읽으면 알 수 있는 사실을 반복하지 않는다. 왜 그렇게 하는지, 무엇을 전제하는지, 무엇을 하지 않는지를 적는다.
- 기호는 용어 문서의 표기 규약을 따르되, docstring 안에서는 수식 조판 없이 평문으로 적는다.
- 사용자가 오해하기 쉬운 지점(마스크의 축, 열의 순서, 계층 관계에 따른 분기)은 반드시 명시한다.
