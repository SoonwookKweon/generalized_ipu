# 예제

`generalized-ipu`의 사용 예제를 담은 노트북이다. 모든 노트북은 실행 결과를 포함한 상태로 보관하므로, 실행하지 않고 읽기만 해도 내용을 확인할 수 있다.

## 목록

| 노트북 | 내용 |
| --- | --- |
| [01_기본_사용법.ipynb](01_기본_사용법.ipynb) | 4계층 자료에 라이브러리가 다루는 여섯 문제를 모두 적용하고 각각을 검증하는 전 과정 |

`01_기본_사용법.ipynb` 는 지역-거처-가구-개인의 4계층 예제 위에서 다음을 다룬다.

| 문제 | 다루는 절 |
| --- | --- |
| $N$계층 구조와 계층에서 유도한 파생 속성 | 1, 2, 4 |
| 구간 목표와 스칼라 목표의 혼재 | 5, 7 |
| $N$차원 교차표 | 3, 4 |
| 범주 위계(소범주와 대범주의 혼재) | 3, 4 |
| 주변표의 결측과 목표 구간의 연역 | 9 |
| 상위 계층 개체 수의 분수 귀속(다가구주택) | 4, 8 |
| 구조적 영과 표본 영의 구별 처리 | 3, 10 |
| 완화 계수의 영향과 실현 불가능한 제약 | 11, 12 |

## 실행 방법

저장소 최상위에서 다음을 실행한다.

```bash
pip install -e .[examples]
jupyter lab examples/
```

노트북은 외부 자료 파일을 요구하지 않는다. 예제 자료는 고정된 난수 씨앗으로 노트북 안에서 생성하므로 실행할 때마다 같은 결과가 나온다.

## 작성 규약

- 예제 자료는 노트북 안에서 생성한다. 별도의 자료 파일을 저장소에 두지 않는다.
- 난수를 쓸 때는 씨앗을 고정하여 결과를 재현 가능하게 한다.
- 설명은 [`docs/01_용어와_정의.md`](../docs/01_용어와_정의.md)의 용어를 사용한다.
- 노트북은 파일을 기록하지 않는다. 저장 절차는 코드 블록으로 보이기만 하고 실행하지 않는다.
- 확인한 사실은 `check()` 로 기록한다. 조건이 거짓이면 그 자리에서 `AssertionError` 가 발생하므로, 노트북이 끝까지 실행되었다는 것이 곧 모든 검증을 통과했다는 뜻이다. 마지막 절에서 기록을 표로 모은다.
- 서술로만 주장하지 않는다. "이렇게 하면 이런 결과가 나온다"고 적었으면 그 결과를 계산하여 대조한다.
